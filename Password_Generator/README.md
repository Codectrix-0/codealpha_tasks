## 📌 Overview

The **Password Generator** is a simple, responsive web application that helps users generate secure and random passwords based on their preferences. Users can customize the password length and choose whether to include uppercase letters, lowercase letters, numbers, and special symbols.


or

Run using **VS Code Live Server**.

---

## 🎯 How It Works

1. Select the desired password length.
2. Choose the character types:
   - Uppercase
   - Lowercase
   - Numbers
   - Symbols
3. Click **Generate Password**.
4. Copy the generated password using the **Copy** button.
