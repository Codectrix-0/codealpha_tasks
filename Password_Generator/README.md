# 📖 About the Project

The **Password Generator** is a modern web application that creates strong, random, and secure passwords based on user preferences. Users can customize the password length and choose whether to include uppercase letters, lowercase letters, numbers, and special characters.

This project was developed as part of the **CodeAlpha Frontend Development Internship** to demonstrate JavaScript fundamentals, DOM manipulation, event handling, and responsive web design.

---

# ✨ Features

- 🔐 Generate secure random passwords
- 📏 Adjustable password length
- 🔠 Uppercase letters support
- 🔡 Lowercase letters support
- 🔢 Number support
- 🔣 Special character support
- 📋 One-click copy to clipboard
- 💪 Password strength indicator
- 📱 Responsive on desktop and mobile
- 🎨 Clean and modern UI

# ⚙️ How It Works

1. Select your preferred password length.
2. Choose the character types:
   - Uppercase Letters
   - Lowercase Letters
   - Numbers
   - Symbols
3. Click **Generate Password**.
4. Copy the generated password with a single click.
